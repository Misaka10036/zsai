# Python 后端业务门户修复与验证（2026-09-21）

范围：智盛fontend、门户回归测试和 Windows 本地 PHP 启动方式。现有 Python 后端接口保持不变。

## 已修复

| 原问题 | 当前行为 |
|---|---|
| 图谱提交失败误报成功、读取失败误报空图谱 | 检查 HTTP、业务 code 和任务 ID；明确显示错误，提交不等同于完成。读取采用请求版本校验，切换知识库不再写入旧结果；空图谱释放旧图表实例以便刷新。 |
| 普通用户看到管理员操作 | 普通用户不显示图谱构建、知识库新建、文档编辑及停止解析入口；PHP 继续校验管理员角色。 |
| 禁用/删除用户后已有登录仍有效 | 每次受保护页面及 API 请求重新读取用户状态和角色，失效账号清除登录。已经开始执行的请求不追溯撤销。 |
| 知识库、聊天、搜索列表只取前 50 条 | 统一列表读取器按页加载全部数据，文件关联知识库和用户管理也使用该读取器；失败明确显示错误。 |
| 文档列表失败显示为无文档 | 检查业务 code，显示错误；丢弃旧知识库的延迟响应。 |
| 上传部分失败无法区分、重试重复上传 | 逐文件显示结果，仅保留失败文件供重试；上传期间禁止重复提交及关闭弹窗。 |
| 上传后缺少解析衔接 | 默认勾选上传后解析，仅提交成功文档 ID；解析提交失败明确说明文件已上传，并提示在列表重试解析。可取消自动解析。运行中/排队任务每 5 秒刷新状态，显示后端进度说明。 |
| 新建搜索应用未绑定知识库 | 创建时必须选择知识库；管理员可以编辑现有应用的名称、描述和知识库。 |
| 搜索请求覆盖新应用、重复提交 | 请求版本与应用关联，切换后丢弃旧响应，同一检索期间禁止重复提交。 |
| PDF 预览依赖未满足、内网资源不可达 | 搜索页统一加载本地 PDF.js、worker、CMap、标准字体和 ECharts；所有页面的 Bootstrap、图标和 ECharts 改为本地资源。管理员原来加载公网 PDF.js，普通用户页原来缺失，现已统一。 |
| Word/Excel 等原文件被当作文本 | 在线预览限于 PDF 和支持的文本格式；其余格式明确提示下载后打开，不显示二进制乱码。 |
| 搜索思维导图无法显示 | 保留搜索流里的 mindmap；未返回时可点击生成，使用普通 API Key 可访问的 Python `/chat/mindmap`，按搜索应用知识库生成，失败可重试。 |
| 聊天新会话残留旧消息、历史读取错误被吞 | 新建会话立即切换并加载该会话；历史读取失败明确提示。 |
| 聊天响应跨会话、重复发送 | 请求与应用、会话及视图版本绑定；同一会话只允许一个回答请求；失败保留问题供重试。 |
| 聊天只显示正文 | 当前回答和历史消息展示引用片段及原文链接。 |
| Agent 假数据/默认流程掩盖错误 | 删除模拟列表、默认流程；列表/详情失败显示真实错误并禁用运行。移除无实现的展开/收起入口。 |
| Agent 停止只改页面、会话不延续 | 先创建真实会话；后续运行带 session_id；停止调用后端取消接口并等待原请求结束，取消失败不提示成功。取消后新建会话，正常连续运行复用会话。 |
| PHP 会话锁和单线程开发服务器阻塞取消 | 长请求前释放 PHP Session 锁。本地启动脚本启动两个普通 PHP worker 和一个专用取消 worker，由同源 Node 代理分发；Ctrl+C 统一清理子进程。 |
| 占位入口和重复实现 | 删除未使用的假解析函数、重复文档列表/分页实现、页脚占位链接和普通用户首页假 Agent 入口。 |
| 本机 PHP 直连地址仍为 Vite 端口 | 本机被 Git 忽略的 config.local.php 已改为 `http://127.0.0.1:9380`；密钥和数据库配置保留。启动脚本仍可用 `-BackendUrl` 覆盖。 |
